# 术语（人话版）

先看左列日常说法，右列是文档里可能出现的词。

| 你听到的 | 简单意思 |
|----------|----------|
| 项目族 | 同一产品拆出来的多个仓库（如项目A / 项目B / 项目C） |
| ralph | 只在 **当前仓库** 从做到验收 |
| same | 把能力 **迁到** 别的同源仓库 |
| dispatch | **多个仓库** 一起预览、批准、派工 |
| review | 把审查结论 **写进任务记录** |
| end | **提交并合分支** 的收工 |
| 交接 / handoff | 从单仓任务带到迁移用的说明（不是聊天记忆） |
| 任务号 task_key | 调度里可接着做的稳定编号 |
| delivery | 一次「多项目交付」的编号（不是要你输入的命令） |
| 调度记录 / control-plane | 多项目派工的状态文件 |
| 验收通过 / VERIFIED | 记录和证据齐了；**不等于** 已推远端 |
| 功能分支 / project-branch | 默认在命名好的 feature 分支上改 |
| Mode S | Grok 上：尽量 **一个会话** 串完多个任务 |
| PENDING | 证据不够，不能当「已通过」 |
| 证据 | 提交、审查文件、调度记录等 **可核对** 的东西 |

更深的架构词见 [架构](architecture.html)。
