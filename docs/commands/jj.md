# jj — 智能意图识别与命令分流入口

当你只知道“我想用 `jj-flow` 处理手头的事”，但一时拿不准该用 `init`、`ralph`、`same`、`dispatch`、`review` 还是 `end` 时，直接使用不带后缀的 **`$jj`（或 `/jj`）**。

它会根据你的自然语言描述判断你的真实意图，告诉你最合适的命令入口并帮你平滑转入；如果关键信息不够（例如没说清要改一个仓还是迁多个仓），它会先向你确认，**绝不会盲目帮你触发跨仓迁移或修改代码**。

| 宿主工具 | 调用写法 |
| :--- | :--- |
| **Codex** | `$jj …` |
| **Claude Code / Grok / Qoder** | `/jj …` |

## 一、适用场景与边界

* **适合使用 `jj` 的情况**：刚接触 `jj-flow` 不想背命令名，或者一个需求既像单仓修改又像跨仓同步，想让 Agent 先帮你判断路径。
* **无需使用 `jj` 的情况**：如果你已经明确知道要做什么（例如就是在当前仓改代码），直接输入 `$jj-ralph` 或 `/jj-ralph` 即可，少绕一层分流。

## 二、分流判定优先级

当你输入 `$jj <一句话描述>` 时，Agent 会按以下固定优先级为你匹配入口：

| 优先级 | 你的意图特征 | 推荐并转入的入口 |
| :--- | :--- | :--- |
| **1. 地图与知识接入** | 提到“加入全局地图”、“梳理目录”、“登记仓库”、“补进知识库” | [init · 项目地图接入](jj-init.md) |
| **2. 跨仓同源迁移** | 提到“把项目A 做好的功能搬到项目B”、“交接到…”、“同步到同源仓” | [same · 跨仓同源迁移](jj-same.md) |
| **3. 多仓统筹调度** | 提到“多个项目一起派”、“先给我看多仓预览表”、“批准分发” | [dispatch · 多仓统筹调度](jj-dispatch.md) |
| **4. 单仓任务闭环** | 提到在当前仓库新增功能、修 Bug、改样式、按验收标准开发 | [ralph · 单仓任务闭环](jj-ralph.md) |
| **5. 只读代码审查** | 提到“审一下刚才的改动”、“做个只读 review” | [review · 只读代码审查](jj-review.md) |
| **6. Git 提交与合并** | 提到“收工”、“提交并合到 dev”、“推送分支” | [end · Git 提交与合并](jj-end.md) |
| **7. 可选辅助引擎** | 明确点名“多角色协同（coordinate）”、“SDLC 流水线（lifecycle）”、“多方案搜索（swarm）”或“离线复盘（evaluated）” | 对应的可选辅助引擎（不替代主流程验收） |

## 三、完整实战示例

### 示例 1：意图明确，直接推荐并转入

```text
你：
$jj 我刚在项目A 做完了登录密码过期提醒，现在想把它搬到项目B

Agent：
你的目标是把项目A 已完成的能力同步到同源仓库项目B，对应入口为 `$jj-same`（跨仓同源迁移）。
在开始迁移前，请确认：
1. 项目A 的改动是否已经 `git commit`？
2. 项目B 当前是否已切换到目标功能分支？
确认后我将按 `$jj-same` 流程为你发起目标仓调研与迁移。
```

### 示例 2：描述模糊，先提问澄清再分流

```text
你：
$jj 帮我处理一下密码过期弹窗

Agent：
为了帮你选对工作流，请确认一下你的具体目标：
1. 如果你是要在**当前仓库**开发或修改这个弹窗 → 建议使用 `$jj-ralph`；
2. 如果当前仓库已经改好提交，要**迁移到其他兄弟仓库** → 建议使用 `$jj-same`（请告诉我目标仓库名称）；
3. 如果代码已经改完，只想**审一下代码**或**提交合入 dev** → 分别使用 `$jj-review` 或 `$jj-end`。
请告诉我你要走哪条路径？
```

## 四、常用说法速查

```text
$jj 把当前仓库加入全局项目地图
$jj 只改当前仓库的票面预览关闭按钮
$jj 把项目A 的登录提醒能力交接到项目B、项目C
$jj 三个项目一起改 README，先给我看预览表
$jj 审一下刚才写的代码
$jj 代码测过了，帮我收工合到 dev
```

## 五、文件记录在哪里？

`jj` 本身只是一个轻量路由器，**不单独创建任何状态文件**。一旦确定并转入目标入口，所有记录均由被选中的工作流（如 `ralph` 在 `.workflow/ralph/`、`dispatch` 在 `~/.jj-flow/`）负责落盘。
