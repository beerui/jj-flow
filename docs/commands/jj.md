# jj — 说不清时用它分流

只说「用 jj-flow」时，用这个入口帮你选路。

| 工具 | 怎么喊 |
|------|--------|
| Codex | `$jj` |
| 其他 | `/jj` |

## 大概怎么选

1. 像「多个项目一起派」→ [dispatch](command-jj-dispatch.html)  
2. 像「交接 / 迁移到别的仓」→ [same](command-jj-same.html)  
3. 像「就在这个仓做完」→ [ralph](command-jj-ralph.html)  
4. 仍不清 → 先问你目标
