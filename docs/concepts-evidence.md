# 什么算「做完了」

## 一句话

**文件和 Git 说了算，聊天不算。**

## 算数 vs 不算数

| 算数 | 不算数 |
|------|--------|
| 任务记录、验收状态 | 聊天里「做完了」 |
| Git 提交 | 会话列表上的状态 |
| 审查结果文件 | 只存在记忆 / 草稿里的内容 |
| 调度里的正式记录 | 模型口头保证「环境 OK」 |

证据不够 → 标成「还不行 / 卡住」，**不要**当成已通过。

## 三层各管什么（知道即可）

1. **本机配置**：项目在哪、调度状态目录在哪  
2. **调度记录**：多个项目谁做了、批没批  
3. **业务仓库**：真正的代码、单仓任务记录、验证说明  

调度只存「指向哪里」，不把业务代码正文抄走。
