# ralph 内部机制 · 可交互演示

**ralph 在干什么？**  
只在**当前这一个业务仓库**里：分析 → 计划 → 改代码 → 验收 → 归档。进度写在仓库内的任务目录，**不是**多仓调度的控制层。

| 叫法 | 是什么 | 默认路径 |
| --- | --- | --- |
| **任务目录** | 单次需求的阶段、检查点、过程 | 业务仓内 `.workflow/ralph/RALPH-…/` |
| **控制层** | 多仓调度状态（dispatch） | 默认 `~/.jj-flow`（ralph 主流程不靠它） |

## 怎么看

1. 点顶部步骤，或「上一步 / 下一步」
2. **自动播放** 看蓝灯怎么走
3. 每步有一句总结 + 你可以怎么说

颜色：蓝=当前 · 绿=完成 · 红=卡住 · 黄=回退

## 故事线（8 步）

1. 任务目录与 run / progress  
2. 五段流水线  
3. 强度档 tiny / standard / strict  
4. 改代码阶段内部循环  
5. 验收：机械层 + 严格档判断层  
6. 归档与能力地图  
7. 相邻阶段回退  
8. 归档后新任务 + 关系字段
