# 目录在哪

## 默认

| 叫什么 | 默认位置 | 干什么 |
|--------|----------|--------|
| 调度状态 | 用户目录下的 `~/.jj-flow` | 多项目派工记录 |
| 项目族根 | 可配置 | 本机多个仓库的根 |
| 知识库 | 可配置 | 跨项目可复用说明 |

一般 **不用你手改**；Agent 会读配置。公司本机若统一配了路径，按团队约定即可。

## 业务仓库里常见目录

```text
.workflow/ralph/…      # 单仓任务记录
.workflow/handoffs/…   # 交接导出
```
