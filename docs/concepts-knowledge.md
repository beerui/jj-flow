# 知识与记忆

聊天 **不是** 正式记忆。能当作依据的是仓库里的记录：任务记录、能力地图（`business-map.json`）、知识库、调度记录。

## 知识库（可选）

跨项目可复用的说明（规范、经验、模式等）。  
默认在用户目录 **`~/.jj-flow/knowledge`**，不打入 npm 包。

### 和 ralph 的关系

开新任务时，会检索**当前项目或同一家族**的相关条目（相关才挂载，没有就空着）。
首次建库、梳理历史贡献走 `$jj-init`。单轮归档后写入知识库，可在 ralph 中说「写入知识库」。**未经你确认不会写入**。

## 记忆热层（用户级）

每个项目一份文件：**`~/.jj-flow/memory/<project_key>.md`**。

- 任务归档时，把 findings 里「可复用结论」晋升为待确认条目
- 经你确认（机械命令 `jj ralph knowledge-confirm`）后，条目标记已确认并置顶
- 开新任务、续做、多项目派发时，自动注入少量相关条目（已确认优先，有条数上限）

聊天内容 **不会** 自动变成正式规范或记忆；进知识库、进热层都要经过文件与你的确认。
